# Juliana Micheal — Developer Portfolio

A responsive portfolio website for **Juliana Micheal**, a Node.js backend developer. It presents her backend skills, selected projects, and direct contact pathways for recruiters and collaborators.

## Highlights

- Recruiter-focused Node.js backend developer positioning
- Responsive layout for desktop, tablet, and mobile
- Featured Task Management API project
- Selected projects with technology tags and repository/demo links
- Accessible navigation, descriptive image alt text, and skip-to-content link
- Direct LinkedIn and GitHub contact calls to action

## Built with

- HTML5
- CSS3
- Vanilla JavaScript
- [Remix Icon](https://remixicon.com/)
- Google Fonts (Manrope and DM Mono)

## Run locally

This is a static website, so no package installation is required.

1. Clone the repository:

   ```bash
   git clone https://github.com/JulianaMicheal/PORTFOLIO-WEBSITE-main.git
   ```

2. Open `index.html` in a browser, or serve the folder with a local development server.

   ```bash
   npx serve .
   ```

## Customisation

- Update project titles, descriptions, tags, and links in `index.html`.
- Replace image files while keeping their filenames, or update their `src` attributes.
- Update the LinkedIn and GitHub URLs to change the contact routes.
- Adjust colours and layout variables at the top of `styles.css`.
